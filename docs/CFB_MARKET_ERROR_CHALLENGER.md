# CFB market-error challenger (research-only)

This branch adds read-only scheduled FBS **shadow forecast artifacts** and a separate **zero-stake** probability challenger. The existing full-history publishing workflow remains disabled, preserving the repository's original Git-publication evidence contract. Neither feature changes the score engine, market release gate, portfolio policy, or places bets.

## Model question

Does the independent Harbin home-win forecast help predict a residual mistake in the sportsbook's **same-game, no-vig home-win probability**?

For each historical paired observation, let `m` be the market probability, `q` the independent forecast, and `y` the realized home win (0/1). The target is `y-m`.

Candidate symmetric residual features:
- `q-m` (independent-vs-market disagreement)
- `(q-m)*(1-|2m-1|)` (close-game disagreement)
- `(m-.5)*(1-|2m-1|)` (favorite-calibration hypothesis)

Estimate coefficients by ridge regression on **2023 only**, using penalties 1/10/100. Select feature family and penalty using **2024 only**. A zero-adjustment model is the default and is retained unless the selected 2024 candidate improves Brier score by at least 0.00025 **and** does not reduce straight-up accuracy. Once choices are frozen, refit the candidate on 2023–2024 and assess on **2025 exactly once**. No 2025 outcome may affect coefficient/family/penalty selection.

The evaluation report compares market-only against challenger by Brier score, log-loss, and outright winner accuracy. It includes sample counts and input SHA. A positive retrospective number is not proof of an advantage because the older archive has already been inspected in previous work.

The historic paired inputs are generated by `scripts/build_cfb_moneyline_diagnostic.py`, matching `reports/backtest_predictions.csv` with free historical prices using the existing canonical archive matcher. These quoted prices are research data; their original sportsbook timestamps **are not verified**, and they may contain final fallbacks.

## Run

In GitHub, run **Actions → CFB Market-Error Research → Run workflow**. The output is an Actions artifact containing `reports/market_error_challenger.json`. The workflow also runs Saturday at 18:13 UTC. It never publishes an official pick or authorizes bets.

Local equivalent:

```bash
python -m pip install -r requirements.txt
python -m pytest -q tests/test_market_error_challenger.py
python -m scripts.build_cfb_moneyline_diagnostic --out /tmp/cfb_paired_research.csv
python -m scripts.market_error_challenger --historical /tmp/cfb_paired_research.csv --out reports/market_error_challenger.json
```

Optional live shadow output requires a **fresh, pre-kickoff** model publication and verified home/away identity. It may be generated via `--live docs/latest.csv --live-audit docs/audit_snapshot.json --shadow-out outputs/market_error_shadow.csv`. Stale output fails; a missing two-sided market fails that row; the official prediction remains unchanged. This is not a live, executable market price or verified closing line.

## Full FBS automation

**Actions → CFB Shadow Forecast (Research Only)** runs at UTC 11:17/17:17/23:17 daily plus Saturday 14:47 UTC. It can also be dispatched manually with both season and week (or neither).

Each run:
1. Runs existing `run_week.py` for the upcoming FBS week, including FBS/FCS forecast-only scope.
2. Fails if the FBS coverage audit finds missing upcoming games.
3. Verifies the generated reporting bundle.
4. Uploads run-specific research artifacts without pushing changes into the repository.
5. **Does not** claim immutable Git-published pregame evidence, refresh the public dashboard, or create official locked picks.

The shadow workflow runs the existing release-gated code path locally and does not publish generated state. The original disabled `.github/disabled-workflows/cfb-model.yml` remains disabled until its full-history and grading protections can be revalidated. The market-error challenger is **not** wired into betting or live prediction decisions.

## Promotion / future validation

A true forward challenge needs a new, time-stamped cohort of pregame prices and independently recorded forecasts. Freeze the challenger weights before kickoff. On the **same** future games, compare market-only, new challenger, and the independent model. Report paired Brier/log-loss, winner accuracy, confidence-pool points, week-block confidence intervals, and calibration by favorite-strength bucket. No retrospective weight changes.

**Do not claim an edge** unless fresh, untouched evaluations show repeatable improvement. For actual wagers, separately require verified executable quotes, price provenance, CLV and economic evidence. Automatic betting is prohibited.
